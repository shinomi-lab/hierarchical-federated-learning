【指示：プレゼン・報告書用サマリーグラフの作成】
現状の解析用グラフは維持したまま、第三者への説明に特化した「Summary Dashboard」用のグラフを以下の仕様で追加生成してください。

1. 成功試行のみを対象とする（データクレンジング）

Roundsが規定数（例：5以上）に達していない、または Final Acc が欠損している試行（今回の試行2, 4など）は、集計および描画から完全に除外してください。  

2. 要約精度曲線（Aggregated Accuracy Curve）の作成

個別の試行（5本の線）は描画せず、成功した全試行の**「平均値の太い線 1本」**のみを描画してください。

その周囲に、標準偏差（1 std）を示すシェーディング（影）を薄い色で重ねてください。  

タイトルは「HFL System Stability (Mean Accuracy)」としてください。

3. 満足度インパクトの比較棒グラフ（QoS Impact Summary）の作成

試行ごとの棒グラフではなく、全成功試行をまとめた**「学習前」と「学習後」の2本の棒だけ**のグラフを作成してください。

学習による満足度の低下幅を一目でわかるようにし、減少率（%）をテキストでグラフ内に注釈（Annotate）してください。  

4. 散布図の明瞭化（Load vs Satisfaction Correlation）

通信遅延と満足度の散布図において、軸ラベルを「Network Load (Latency)」と「User Satisfaction」に簡略化してください。  

グラフ内の空白スペースに「Lower right: Communication load impairs UX（右下に行くほど、通信負荷がユーザー体験を阻害していることを示す）」という解説を挿入してください。  

5. 要約テーブルの出力

multi_trial_analysis_2.md とは別に、成功試行の平均値（Mean）と標準偏差（Std）のみをまとめた1行だけのサマリー表を出力してください。
