# 2サイクル目移行問題の修正報告書

ユーザーからの「学習ボタンを押してから1サイクルで終了してしまう（2サイクル目に移行しない）」という問題に対し、以下の修正を行いました。

## 1. 原因
*   UIから呼び出される `startTraining` メソッドが、単発の学習（1サイクルのみ）を実行する古い実装のままでした。
*   5サイクルループや自動モデル更新のロジックを持つ `runFiveCycles` メソッドが呼び出されていませんでした。

## 2. 修正内容
*   `startTraining` メソッドを全面的に書き換え、内部で `runFiveCycles` を呼び出すように変更しました。
*   これにより、以下のフローが正しく実行されるようになります：
    1.  学習開始（サイクル1）
    2.  アップロード
    3.  ラウンド更新待機
    4.  新モデル取得（能動的フェッチ）
    5.  次サイクル開始（サイクル2...）

## 3. 期待される動作
*   学習ボタンを押すと、5サイクル分の学習が自動的に進行します。
*   各サイクルの合間にサーバーとの同期（アップロード・ダウンロード）が行われます。
*   5サイクル全て完了するまで、学習完了フラグ（ボタンのグレーアウト解除）は立ちません。

以上で、ご指摘の問題は解消されるはずです。
