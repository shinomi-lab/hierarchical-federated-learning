## 3. 各指標の詳細分析

### 3-1. 学習精度（Val Acc）の推移

```
精度推移（概略）
 90% ┤                                              ●
 85% ┤                                         ●●●●
 80% ┤                                    ●●●●
 75% ┤                               ●●●●
 70% ┤                          ●●●●
 65% ┤                     ●●●●
 60% ┤                ●●●●
 55% ┤           ●●●●
 50% ┤      ●●●●
 45% ┤ ●●●●
 40% ┤●
     └──────────────────────────────────
     1   5   10   15   20   25   30 (Round)
```

**観察事項：**
- **Round 1〜8**：急速な初期学習フェーズ。ランダム初期値（25%付近）から50%以上へ急上昇
- **Round 9〜20**：安定成長フェーズ。毎ラウンド約1〜2%の単調改善
- **Round 21〜30**：収束フェーズ。75%を超えてから伸びが緩やかになる
- **Round 30**：平均 **81.13%**（4クラス分類の理論ランダム精度 25% に対して大幅な改善）

**ばらつきの変化：**
- Round 1：std = 3.10%（初期学習の不安定性）
- Round 10：std = 4.84%（シードによる差が拡大）
- Round 30：std = 3.57%（収束に伴いばらつきが縮小）

### 3-4. AP 切替回数の分析

各ラウンドの切替数（3端末合計）の10回平均：

```
Round 1:  平均 0.9 回/ラウンド（モデル未収束 → 不確実な切替多い）
Round 5〜29: 平均 0.2 回/ラウンド（収束に伴い安定）
Round 6,9,10,11,14,19,30: 平均 0.0 回（全端末が適切なAPを維持）
```

**解釈**：
- 初期ラウンド（Round 1）でのみ切替が集中（モデル信頼性が低い段階）
- Round 10 以降は確信度が 0.85 を超え、不必要な切替が減少
- 最終 Round では切替なし＝全端末が最適な AP に安定接続

- ばらつき：std = 2.9 ラウンド → 比較的安定した収束

### 4-2. 収束の特徴

```
収束の定義: 最終精度の95%以上に到達した最初のラウンド

例: 最終精度 81.13% → 閾値 = 81.13% × 0.95 = 77.07%
    → Round 24付近で 74.77% を超え始める
```

**注目点**：最終精度が高いからといって収束が早いわけではない。
- Run e66fa345：最終精度 **88.67%**（最高）かつ収束 Round 23（比較的早い）
- Run 4236cecc：最終精度 **85.00%**（2位）だが収束 Round 27（やや遅い）

これは学習の軌跡（どのラウンドで大きく精度が跳ね上がるか）の違いによる。

## 5. 考察

### 5-1. HFL の学習有効性

- 4クラス分類において最終精度 **81.13%** は、ランダム予測（25%）の **3.2倍**
- 累積学習（モデル引き継ぎ）により、30ラウンドを通じて単調な精度改善を確認
- 損失も 1.35 → 0.52 と61.5% 削減し、学習の安定性を示す

### 5-2. AP 選択の有効性

- 全ラウンド平均満足度 **94.39%** は、AP 選択なし（ランダム割り当て）と比較して
  高水準の QoS 維持を実現していることを示す
- `sat_after > sat_before` の傾向（平均+2.9pt）は、モデルの推薦が
  少なくとも現状維持以上の品質を保証していることを意味する
- 確信度が 0.85 を超える Round 10 以降は切替が安定し、
  **EMA + 連続判定による DecisionEngine の抑制機構** が適切に機能

### 5-3. 収束速度とラウンド数設計

- 平均収束 Round **25.7 / 30** は、30ラウンドという設計がタイトであることを示す
- 5回中 4回が Round 25 以降に収束しており、余裕をもった収束のためには
  **35〜40 ラウンド** が望ましい可能性がある
- ただし実機実験のリアルタイム性の観点では、Round 20 付近（精度 69%、確信度 0.93）
  で十分な AP 選択品質（満足度 95%+）が得られており、
  **実用的収束は Round 20** と解釈できる

### 5-4. 実験間ばらつきの要因

| 要因 | 影響 |
|---|---|
| 初期モデル重み（シード依存） | 学習初期の精度ばらつきに影響（std最大 0.054） |
| データ生成の乱数 | 訓練データの分布ばらつき |
| AP 初期割り当て | call端末がどの AP から始まるかで満足度が変動 |
