# エッジサーバ仕様書（最新版）

## 概要
このドキュメントは、エッジサーバ（端末側）の最新仕様変更点と運用ルールをまとめたものです。ラウンド管理とログ管理の一貫性を確保し、サーバの起動・シャットダウン時の動作を明確化します。

---

## 変更点

### 1. ログ管理の統一
- サーバ起動時に新しいログファイル（`logs/time_records/edge_server_<timestamp>.log`）を生成。
- サーバシャットダウン時にログファイルへ「終了」メッセージを記録。
- ログ設定は`logging_config.py`で一元管理。

### 2. ラウンド状態管理の初期化
- サーバ起動時にラウンド番号を必ず「1」にリセット。
- サーバ再起動時もラウンドは「1」から開始。
- ラウンド番号は`state.py`の`current_edge_state.round`で管理。

### 3. サーバーライフサイクルイベント
- 起動時：ラウンド番号リセット＋ログ出力
- シャットダウン時：ログ終了メッセージ出力
- FastAPIの`startup`/`shutdown`イベントで制御

---

## 使用方法

### サーバの起動
```bash
python edge_server/main.py
```
- 起動時にラウンド番号が「1」にリセットされ、ログファイルが新規作成されます。

### サーバのシャットダウン
- サーバを手動で停止（例：Ctrl+C）
- シャットダウン時にログファイルへ終了メッセージが記録されます。

---

## ディレクトリ構造
```
logs/
  time_records/
    edge_server_<timestamp>.log
```

---

## 注意点
- ログファイルは毎回新規作成され、タイムスタンプで区別されます。
- ラウンド番号はサーバ起動ごとに「1」から開始されます。
- 端末側でラウンド番号を永続化・引き継ぐことはありません。
