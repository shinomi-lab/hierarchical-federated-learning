# device_client.py

概要
---
`device_client.py` はエッジサーバへ学習メトリクスやサンプルファイルを送信するための軽量なクライアントシミュレータです。ローカルにメトリクス／サンプルを保存し、指定のラウンドごとにまとめてアップロードする動作を模擬します。開発・検証用に作られており、将来的に Android 版クライアントへ移植しやすい構造になっています。

主な機能
---
- 学習ラウンドのシミュレーション（メトリクスとバイナリサンプルの生成）
- メトリクスの集約（JSONL）とサンプルファイルのローカル保存
- 一定ラウンドごとにエッジサーバへメトリクス（単一オブジェクト）を POST
- サンプルは multipart/form-data で個別にアップロード
- 再試行（指数バックオフ）による堅牢な HTTP 通信

設置場所
---
`edge_server/clients/device_client.py`

依存関係
---
- Python 3.8+（Pathlib と型アノテーションを利用）
- requests

インストール例
---
PowerShell:

```powershell
python -m pip install --user requests
```

使い方 (コマンドライン)
---
基本実行例:

```powershell
python device_client.py --base-url http://192.168.11.2:8001 --token secret-token --device-id device-001
```

引数一覧:
- `--base-url` : エッジサーバのベース URL（既定: `http://192.168.11.2:8001`）
- `--token` : サーバ認証トークン（既定: `secret-token`）
- `--device-id` : このクライアントの端末 ID（既定: `device-001`）
- `--total-rounds` : 実行する総ラウンド数（既定: `10`）
- `--rounds-per-upload` : まとめてアップロードするまでのラウンド数（既定: `5`）
- `--round-interval` : ラウンド間の待ち時間（秒、既定: `2.0`）

内部の保存先
---
スクリプトはデフォルトでプロジェクト内 `state/training_data/` にメトリクス（JSONL）とサンプル（.bin）を保存します。

ログと出力
---
- 標準出力に進捗情報をログ出力します。失敗や再試行は WARN/ERROR レベルで出力されます。

設計上の注意点 / 運用上の留意点
---
- 本スクリプトはシミュレータであり、実機 Android クライアント同等のセキュリティや権限管理は実装していません。
- 本番で利用する場合はトークンの安全な管理、TLS（https）、および適切なリトライ／バックオフポリシーの見直しを行ってください。
- `--base-url` を指定しない場合、環境変数や設定ファイルで上書きできる仕組みがプロジェクトにある場合はそれに従ってください（このリポジトリでは `AppConfig` にデフォルトを持ちますが、Python ツールは環境変数優先です）。
